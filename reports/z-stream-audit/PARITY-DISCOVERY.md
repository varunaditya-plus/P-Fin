### Final browser-review corrections

- Root live QA confirmed Dune's three-film Seerr collection and rating sorting.
- Root found that the Seerr person modal could render but not receive pointer/keyboard input. Its dialog was a sibling of the still-active title dialog, so their focus traps competed. Person details now render inside the parent dialog's React tree, as in Jellyfin details. A mounted regression test verifies focus ownership, Read more, and Escape closing only the person dialog. The separate Jellyfin dialog intentionally remains outside: Seerr hides itself when opening library details.
- Root found a blank YouTube trailer iframe in IAB. Both YouTube embed hosts returned HTTP 200 with valid HTML from the machine, and the app sent no blocking CSP/frame-src header. A concrete app issue was identified: the global `<meta name="referrer" content="same-origin">` suppresses cross-origin identification. The trailer iframe now explicitly uses `referrerPolicy="strict-origin-when-cross-origin"`, matching [YouTube's documented embedded-player identification requirement](https://developers.google.com/youtube/terms/required-minimum-functionality#embedded-player-api-client-identity). The global policy and privacy-enhanced embed host remain unchanged. A regression assertion verifies the override. Post-fix IAB testing still showed blank local playback with two Dune videos and both `youtube-nocookie.com` and `youtube.com`. The standard-host experiment was reverted. A reference-site Elite trailer did play in the same IAB, so this is not a demonstrated general IAB limitation. Root verified the local iframe is visible, correctly sized and topmost, with no CSP/COOP/COEP response headers. HTTP success alone does not establish playback. Final source inspection found no iframe sandbox, global iframe CSS or blocking code, unstable iframe key/src, or active-child Dialog inerting; no further cause was established and no speculative change was made. Local trailer playback remains an unresolved browser-validation limitation.
- These final corrections passed three mounted related/person tests, full TypeScript and scoped ESLint.
